# Majonk Migration
<img align="right" src="https://github.com/user-attachments/assets/f83c558b-0b03-40a4-9e8c-6e04464792a3" width="200" />

Another year — another migration.

It's a server-side solution of the recent UUID API problem for the 7.3_03 BTA! servers.

---

Note, that clients should install this mod too or provide their UUID in launcher args, using 

`--args="--username <name> --uuid <uuid>"`.

You can see your UUID following this link:

`https://api.minecraftservices.com/users/profiles/minecraft/<your nickname>`
